<h1>osTicket - Ticket Lifecycle: Intake Through Resolution</h1>
This demonstration outlines the lifecycle of a ticket from intake to resolution within the open-source help desk ticketing system osTicket.<br />


<h2>Video Demonstration</h2>

- ### [YouTube: How to create, work, and resolves tickets within osTicket](https://youtu.be/-9elep6r1z8)

<h2>Environments and Technologies Used</h2>

- Microsoft Azure (Virtual Machines/Compute)
- Remote Desktop
- Internet Information Services (IIS)

<h2>Operating Systems Used </h2>

- Windows 10</b> (21H2)

<h2>Ticket Lifecycle Stages</h2>

- Intake
- Assignment and Communication
- Working the Issue
- Resolution

<h2>Lifecycle Stages</h2>
<h2>Intake</h2>
<p>
<img src="https://github.com/user-attachments/assets/8cd38483-1c2f-4d49-8f6d-1a0a70ed81bf" width="70%" alt="Disk Sanitization Steps"/>
</p>
<p>
When a User submits a ticket, they're able to enter a help topic and an issue summary. This can either be done directly by the user through the ticketing system, or manually entered by an admin or support staff.
</p>
<br />

<h2>Assignment and Communication</h2>
<p>
<img src="https://github.com/user-attachments/assets/b53aacd6-3749-459a-bbc6-296639a29e40" width="70%" alt="Disk Sanitization Steps"/>
</p>
<p>
Upon ticket submission, any Agent who has access and permissions to the ticket will be able to view it and make changes, such as assigning it an SLA, a priority level, department, and assigning the ticket to be worked by an individual or team.
</p>
<br />

<h2>Working the Issue</h2>
<p>
<img src="https://github.com/user-attachments/assets/cae4164f-8aad-4226-a464-d20b26c2e755" width="70%" alt="Disk Sanitization Steps"/>
</p>
<p>
From this point, whoever has been assigned the ticket will communicate with the user to clarify any more information that is necessary to resolve the issue. If it's an ongoing problem, even if no progress has been made, it is still a good idea to keep in communication with the user so they know they're problem is still being worked on. When a solution is found, contact the user to make sure everything is functioning well on their end.
</p>
<br />

<h2>Resolution</h2>
<p>
<img src="https://github.com/user-attachments/assets/e1a4b06f-771b-451d-9e2d-b941f834c775" width="70%" alt="Disk Sanitization Steps"/>
</p>
<p>
Once the issue is confirmed to be resolved, the ticket status can be changed to "Resolved" along with a message where we can put a short summary to document what caused it and how it was resolved.
</p>
<br />
